# 幼儿园 STEAM 教案助手

面向中国大陆幼儿园老师的手机网页应用，也支持电脑浏览器。老师输入一个想法，一屏回答 4 个问题，生成适合小班、中班或大班的教案；可继续改稿、回退版本、生成打印配图并下载 Word。

项目用于非商用研究。教学框架来自教材提炼，不做原书全文 RAG。

## 本地运行

后端要求 Node.js 20+、PostgreSQL 14+；当前锁定的 Vite 8.2.2 要求 Node `^20.19.0 || >=22.12.0`。依赖安装在本地硬盘，避免 Google Drive 虚拟盘的文件写入问题。

首次先按 [后端运行说明](backend/README.md) 建库、配置环境变量并执行迁移。之后分别打开两个终端：

```bash
# 终端一，从项目根目录开始
cd backend
npm install
npm start
```

```bash
# 终端二，从项目根目录开始
cd frontend
npm install
npm run dev
```

前端地址以 Vite 输出为准；开发代理指向后端 `localhost:3000`。Windows 可使用根目录 `admin.bat` 和 `teacher.bat`，关闭服务窗口即停止服务。后端改动后需手动重启；生成任务进行中不要使用自动重启。

首次使用在 `/redeem` 输入有效兑换码，选择名单身份或填写名单外信息，再设置手机号和密码；已有账号使用 `/login`。兑换码由管理后台创建。旧微信登录及开发假登录已移除，无需微信变量。

## 当前能力

- 手机号与密码登录、兑换码激活及续兑、个人档案、记忆、任务、反馈和退出登录。
- 一屏 4 题、异步生成、学习模式教案解读、改稿与版本回退。开启内容审核时只展示生成进度，审核通过后展示正文。
- 打印配图、磁盘存储与压缩；Word 直接下载文件，Markdown 返回文本。导出含设计意图，不含学习模式折叠解读。
- 管理后台支持园所、名单、老师、兑换码、额度、任务、反馈与模型管理，并区分管理员和超管权限。
- 阿里云文本内容安全已接入；配图描述接受文本审核，图片本身尚未接入审核。

当前待办及有日期的部署记录统一见 [CLAUDE.md](CLAUDE.md)，不在多个文件重复维护进度。

## 目录与技术

| 目录 | 用途 |
|---|---|
| `frontend/` | Vue 3、Vite、vue-router，教师网页 |
| `backend/` | Express、原生 JavaScript ESM、PostgreSQL 手写 SQL，含管理后台 |
| `docs/design/` | 当前接口及专题规范 |
| `docs/adr/` | 有日期的架构决策；后续决定可能替代早期方案 |
| `docs/handoff/` | 各轮交接，描述当时发生的事 |
| `prototype/`、`design-demos/` | 历史原型与设计资产 |
| `Archive/mini-program/` | 已停止开发的小程序版本 |

模型由后台管理，凭据只在服务端。图片使用单机磁盘方案，`OBJECT_STORAGE_*` 是保留的旧配置，不是部署必填项。测试入口、条件与副作用见 [后端运行说明](backend/README.md#验证与测试)。
