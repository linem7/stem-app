## 下一轮要做什么

用户原话：**「下一轮我会针对一些按键的小细节进行调整」**。

所以下一轮大概率是**管理后台按钮/文案/位置的微调**，不是新功能。
需要知道的三件事：

### 1. 后台的界面代码在哪

管理后台是**纯静态页面**，`app.use('/admin', express.static(...))` 直接发文件，
**没有构建步骤**。改完刷新浏览器就生效，**不用重启后端**。

| 文件 | 装什么 |
|---|---|
| `backend/admin/index.html` | 全部 CSS + 设计令牌 + 布局 |
| `backend/admin/app.js` | 概览 / 园所 / 教师 / 兑换码 / 反馈 / 管理员 / 操作记录 / 个人中心 |
| `backend/admin/roster.js` | 名单的**动作**（导入 / 岗位调整 / 作废）。列表已并入教师页 |
| `backend/admin/tasks.js` | 任务页与任务详情 |
| `backend/admin/image-models.js` | 配图模型页 |

只有改 `backend/src/routes/admin.js`（接口本身）才要重启后端。

### 2. 🔴 术语规则（这一轮刚定的，别违反）

**管理后台一律用规范术语，不用口语。** 用户 08-22 的全局要求，我按它改了一百多处。

- 「收了」→ 停止、「改」→ 编辑、「看码」→ 查看兑换码、「她换班了」→ 岗位调整、
  「等她来认领」→ 待激活、「谁在用」→ 使用情况、「老师」→ **教师**
- ⚠️ **这条只管管理后台。小程序那一侧（`frontend/`）保持口语化** ——
  那是设计方向定的，老师不是运营人员。用户没说要改小程序
- **代码注释不改**：口语化在注释里是资产
  （「她被叫走进度不能丢」比「需保证会话状态持久化」更让人记得住为什么）

界面小字另有一条更早的规则（CLAUDE.md「界面上不要写解释性小字」，用户已提过五次）：
写每一句副标题前先问「她不看这句话会做错什么吗」，答不出来就删。
只有两种小字留得住：**边界说明**（不说会被当成 bug）和**不可逆动作的后果**。

### 3. 界面的事可以自己量，不用等用户看

`npm run dev:h5` 那套是给小程序的；**管理后台更简单** —— 它就是一个普通网页：

```
1. 起一个测试后端：cd backend && PORT=3100 node src/server.js
2. chrome-devtools 打开 http://localhost:3100/admin/
3. 登录：fetch('/admin/api/login', ...) 拿 token 塞 localStorage，然后 location.reload(true)
4. 量：getBoundingClientRect() / 读 textContent / 直接调 window.goto('teachers') 翻页
```

⚠️ **别在用户那个 3000 上跑测试** —— 那个窗口是他的后端本体（`admin.bat`），
而且它跑的常常是旧代码（后端没开 `--watch`，改了要重启）。

管理后台**没有**「只有微信才出错」那一类问题（无样式隔离、无 WXML 编译、
无 handler 缓存 key），所以浏览器里量出来的就是结论。

## 🔴 这一轮最值得记住的两件事

### 一、六个回归脚本原来不读 `API_BASE`，我因此报过一次假的「全绿」

`activation` / `admin` / `ops` / `rebind` / `roles` / `tasks` 六个脚本
把 `http://localhost:3000` **写死**了。所以「另起 3100 跑回归」那条说明
**一直是假的** —— 它们打的是用户那个跑旧代码的窗口，而数据库是共用的，
于是我看到的绿是「旧代码 + 新数据」，并据此向用户报告了「11 个全绿」。

**六个都改成读 `API_BASE` 了。加新脚本照 `import-test.mjs` 那一行写。**

教训比 bug 本身重要：**验证工具本身也要验证**。
「脚本跑完是绿的」不等于「它测的是我改的那份代码」。

### 二、顺着这条查出三个先前就存在的缺陷

都属于「生效和不生效、正常输入下输出一模一样」那一类
（跟 CLAUDE.md 里白名单、硬校验那几条同族）：

| 缺陷 | 为什么看不出来 | 修法 |
|---|---|---|
| 老师**续兑第二个码**后在列表里出现两次 | 额度数字全是对的，看起来像数据重复不像查询写错 | `LEFT JOIN redemption_codes` 改标量子查询；搜索走 `EXISTS` 遍历她全部的码 |
| 没填姓名的人显示成 `**` | `surnameOf(null)` 是空串。而 `'**'` 是**真值**，任何 `filter(t => t.real_name)` 都把无名的人算成有名的 | 收成一个 `maskName()`，无名回 `null` |
| 同一个人姓名有**两个来源** | 列表取名单行、详情取账号行，而换班时新开名单行**不回写** `teachers.real_name` → 列表显示「甲小美」、点进详情是 null，两处都不报错 | 详情改成跟列表同一套顺序（名单优先、账号兜底） |
