## 会绊倒你的几件事

### 1. 开发要两个 cmd 窗口

`npm run dev` 是服务器，会一直占着它那个窗口。

```
窗口一  双击根目录 admin.bat            后端，3000
窗口二  cd frontend && npm run dev      前端，5173
窗口三  cd frontend && npm run dev:account   造一个已激活的账号
```

第三条把账号写进 `.env.development` 的 `VITE_DEV_OPENID`，vite 自己重启，**刷新浏览器就行**。

🔴 **不跑第三条的话首页会跳去 `/redeem`**，而那一页还没搬 —— 表现是一个 toast
「跳转目标不存在：redeem」。
⚠️ `cleanup-test-data.mjs` 会把这个账号一起删掉（它建的园叫「契约测试园_xxx」），清完再跑一次。

### 2. 拿真手机看

`vite.config.js` 里 `host: true`，同一个 WiFi 下手机直接开
`http://<这台电脑的内网 IP>:<端口>/`（`ipconfig` 查 IPv4）。
开发者工具那个模拟框看不出滚动惯性、输入法顶起页面、系统字号调过这些事。

### 3. Bash 里用 `node -e` 改文件会吃掉 `$` 变量

这一轮踩了两次：双引号包着的 node 脚本里 `$sp-3`、`$rule-2` 被 shell 展开成空，
写进 scss 就是 `margin: 0 -3 5px`，报的是 `[sass] Expected expression`，
错误位置指向的行看起来完全正常。**改 .vue 用 Edit 工具，别用 node -e**。

同一类：`indexOf` 找注释标记做切片时，那个标记如果在 script 和 style 里各有一份，
会切出重复的一整段（s-plan.vue 被复制成 2289 行）。

### 4. 两个滚动 watcher 会打架

教案写完那一刻，`writing` 由 true 变 false，而「滚到底」和「停在教案开头」两个
watcher 都会被触发。不挡住就被拽到底（实测 scrollY 2121，教案顶在视口上方 1947px）。
「滚到底」只能在**开始写**和**追问冒出来**时触发。

### 5. 改稿那次轮询会超时

`pollGenerate` 上限 120 秒。改稿要重读教案 + 意见 + 三题答案，比首次生成慢，
实测撞上过一次超时 —— 后端其实成功了，刷新就能看到新一版。
**这不是这一轮引入的**，但改稿这条路上更容易撞到，值得调一调那个数。
