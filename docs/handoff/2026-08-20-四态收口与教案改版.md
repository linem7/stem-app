## 这一轮真踩过的坑

### 1. 🔴 我给 `admin.bat` 加了 `--watch`，当天撤回

**这条最要紧，因为它是我自己造成的，而且差点长期存在。**

「改后端代码必须重启」每轮都要记一次，所以我把 `node src/server.js` 改成了 `--watch`。
结果提交一张配图，日志是：

```
10:44:03.345  task_enqueued  img_118
10:44:03.384  POST /51/images → 200
              Restarting 'src/server.js'      ← 一秒内
```

任务被重启当场杀掉，图片行永远停在 `pending`。根因在 `services/taskQueue.js`
文件头**第一行**就写着：「进程重启，排队中和执行中的任务会丢」——队列在内存里。
而生成教案 20–30 秒、配图 20–70 秒，`--watch` 是在**任务进行中**开火的。

教训有两层：一是**改工具链之前先读那个工具链依赖的东西的注释**；
二是「省掉一件要记得的事」换来「核心功能静默丢任务」是坏交易。
理由连时间戳已经写进 `admin.bat` 的注释，标了「不要在这里加 --watch」。

### 2. 用户「双击了 admin.bat」不等于后端换了新代码

`admin.bat` 检测到 3000 上已有后端时**只开浏览器、不起新进程**（PowerShell 一闪就关）。
用户以为重启了，实际跑的还是旧代码，于是「你改的东西我看不到」。
正确顺序：先在那个窗口 Ctrl+C，再双击。

**核实一句**：`wmic process where "ProcessId=<pid>" get CommandLine`。
我这一轮是查了这句才发现自己前面所有后端改动都没生效的。

### 3. 两个「一直写在文档里、但从来没成立」的东西

- **`design-tokens` 规则 2**：「配白字用 deep 档就达标」写了一年。
  实测旧 `$mint-deep` 配白字 **3.97:1**、当绿字压浅绿底 **3.57:1**，两个都不到 4.5。
  → 已压暗，并加了 `npm run test:contrast` 逐对算 WCAG
- **`enforceAgeBand` 的反向测试**：CLAUDE.md 写着「用故意违规的样本测过，红线全抓得到」，
  而那是某次会话里手动跑的，**没有脚本**。
  → 加了 `npm run test:ageband`（23 条）

共同点：**空转的校验和严格的校验输出完全一样**（都是零违规）。
所以「规则写在文档里」和「规则被执行」是两件事，后者需要一个会红的脚本。

### 4. `smoke.js` 根本跑不起来

激活闸门是 08-17 加的、一屏 4 题是 08-17 改的，它两处都没跟上，
`POST /conversations` 直接 403。而 CLAUDE.md 里一直写着「冒烟脚本 npm run smoke」。
**能跑起来的脚本才叫回归。** 已修好（自造园所 + 名单岗位 + 兑换码，可反复跑）。

### 5. 我写的第一版回归脚本自己就不可反复跑

`mode-test` 第一版一口气开 12 个会话，撞上「每小时 10 个」的限流。
限流是对的，是**脚本设计错了**——一个跑第二遍就红的脚本，红两次之后没人看。
改成把乱值收敛当**纯函数单元测**，只留一次 HTTP 证明路由走了它。会话数 12 → 5。

顺带：那一节抓到 `resolveMode(['learning'])` 会漏过去（`String(['learning'])`
正好等于 `'learning'`），已改成先判类型。

### 6. 微信自定义组件的样式隔离会让字号档静默失效

`app.wxss` 里的**类选择器进不了自定义组件内部**（只有标签选择器能穿透，
所以 `page {}` 那层可以）。我第一版用 `.fs-lg` 类挂在 `s-page` 根节点上——
那个节点正在组件内部。这条会**静默失效**：编译不报错、H5 预览还是对的
（H5 没有样式隔离），只有微信里「调到特大什么都没变」。
改成内联 CSS 变量。**这类问题只有读 `s-page.json` / 编译产物才发现得了。**

### 7. 断网那一屏第一版在说谎

写的是 `net.online ? '网回来了' : '还是没有网络'`。浏览器里真断网一测，
网明明断着它写着「网回来了」——因为 uni 的 H5 实现不烧 window 的 offline 事件。
而且 `NETWORK` 这个 code 本来就包含「wifi 好得很、是后端连不上」。
改成**只说否定的那一面，网通着就一个字都不说**。

## 与用户协作的注意事项

**先读 `MEMORY.md`**，那是这一轮专门为此建的，比这一段全。三条最要紧的：

- **每轮交付给一张 summary table**（做了什么 / 还差什么），然后单独说清「你需要做什么」。
  他 2026-08-20 明确提的
- **界面上不写解释性小字。** 判据：她不看这句话会做错什么吗？答不出来就删
- **他会推翻自己上一个决定。** 遇到反转不要急着实现——先把新方案的代价说清楚，
  他接受了再动。这一轮反转了一次（首页插画、「去看教案」按钮）
- **他在微信开发者工具里看效果，你看不到。** 每次交付都要如实说「好不好看得你自己看」
- **给他指元素看用 `http://localhost:5173`**（H5 dev server，跑的是真源码，
  DOM 类名跟 `.vue` 文件一一对应）。**不是** `prototype/index.html`——那是手写镜像，
  在它上面指元素改不到任何代码
