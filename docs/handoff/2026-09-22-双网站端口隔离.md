# 两个网站共用 IP 的入口准备

2026-09-22：用户要求试用期在同一 IP 同时部署教案与问卷网站，暂无域名。

| 入口 | 当前状态 |
|---|---|
| https://115.29.167.18（443） | 现有教案网站，登录页 200，healthz 正常 |
| https://115.29.167.18:8443 | 独立 Nginx HTTPS 入口，尚未连接问卷项目，固定返回 503「问卷网站尚未部署。」 |

配置 `/etc/nginx/sites-available/survey-app`，复用现有 IP 证书及自动续期。主机 UFW 已放行 8443。通过本地 resolve 验证 TLS 证书成功（verify=0）。通过公网 IP 访问 8443 超时，仍需用户核对阿里云安全组放行 TCP 8443；不能将本地验证视为公网可达。

Cookie 不按端口隔离。已核对教案老师端和管理端均使用 Authorization token，不依赖 Cookie。因此在 `/etc/nginx/proxy_stem.conf` 去掉发往教案后台的 Cookie，并隐藏来自教案后台的 Set-Cookie。不同端口提供不同 origin，localStorage 分开；这并非两个互不信任网站之间的完整安全边界。

问卷真实部署时仍需：独立进程、独立数据权限；Cookie 使用 Secure/HttpOnly；校验写请求 Origin（包含 8443），防止同 IP 跨端口请求携带 Cookie；转发 Host 必须保留外部端口；生成/恢复链接带正确外部地址。禁止共用通配 CORS 凭据访问。
