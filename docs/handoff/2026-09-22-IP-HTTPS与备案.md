## 广东省备案材料

按阿里云广东规则，准备身份证原件彩色照片、本人人脸核验、手机号、邮箱和真实通信地址。

- 证件住所不在广东：提供广东居住证、房产证等或三个月社保证明；学生异地备案不能只提供学生证，按规则提供居住证或暂住证。
- 订单内下载打印《互联网信息服务核准承诺书》，本人用黑色或蓝色笔签字后拍照上传。
- 域名持有人与主办人一致，完成实名认证，剩余有效期大于 30 天。
- 个人网站数量超过五个才触发每站网站建设方案书的数量规则；组网方案等其他材料按订单清单提供。
- 先核实 AI 教案生成服务是否适用个人备案，不能认为非商用研究用途必然适用。

给备案客服的业务说明：

> 我计划在大陆 ECS 部署非商用研究项目网站，面向合作幼儿园成年教师。教师登录账号，输入教学需求，通过第三方模型接口生成、修改、下载教案及配图。拟以广东个人主体备案，请确认是否接受此业务、是否需要单位主体或额外材料，并告知网站名称和服务内容填写要求。

## 阿里云步骤

1. 使用购买现有 ECS 的账号登录 https://beian.aliyun.com/ ，先核实主体适用性及可备案实例。
2. 阿里云只支持域名备案，准备实名域名。现有 ECS 需满足大陆、公网带宽、包年包月至少三个月等条件；旧记录称按量付费，本轮未查询当前账单，不要盲目另购实例。
3. 开始备案 → 网站 → 广东及真实主体类型 → 填写主体、域名、负责人、网站内容 → 关联可备案实例。
4. 上传材料、人脸核验、提交初审，接听审核电话。
5. 收到工信部短信后 24 小时内到 https://beian.miit.gov.cn/ 完成核验，再等待管局审核。
6. 通过后配置域名解析与 HTTPS、页面底部备案号；按官方要求办理公安联网备案。

大陆裸 IP 对外提供网站服务仍需备案；HTTPS 不代替备案。旧文档“IP 不能签证书”“内测自动免备案”已过时或不正确。
