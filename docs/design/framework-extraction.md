# STEAM 教案框架提炼

源自：《臺北市幼兒STEAM教案彙編成果輯》

---

## 一、STEAM 教学核心理念（5 大支柱）

### 1. 以解决真实问题为焦点
- 源自生活经验和日常现象
- 学生主导，从他们的观察和好奇出发
- 例：如何做出好吃的芝士 → 7 周探究过程

### 2. 动手做、探究取向的学习
- PD/OQ/DE/T 循环模型（预测→动手做→观察→提问→讨论→解释→迁移）
- 失败与反思并重，持续尝试改进
- 例：麵粉加水实验反复调整，从 10cc 到 80cc 找到最优比例

### 3. 跨学科统整（非简单拼凑）
- 五个领域有机融合，不是独立教学
- 每个活动同时触及科学、技术、工程、艺术、数学
- 例：做蝴蝶面同时涉及粘合性(S)、揉面技巧(T)、比例(E)、形状美学(A)、测量(M)

### 4. 培养 7 个 C 素养
- **Communication**（表达交流）
- **Cooperation**（合作）
- **Cross-content**（跨领域知识）
- **Critical thinking**（批判思维）
- **Creative thinking**（创意思维）
- **Confidence enhancement**（自信心）
- **Continuous improvement**（持续改进）

### 5. 与课纲理念高度一致
- 以幼儿为学习主体
- 基于幼儿的生活经验和真实问题
- 师生共构课程
- 提供充足自由探索机会

## 二、优质 STEAM 教案的质量标准（8 个维度）

| 维度 | 标准 | 验证方式 |
|------|------|---------|
| **问题的真实性** | 源自幼儿日常生活或学校情境，而非教师预设 | 教案特色说明中明确说明问题来源 |
| **探究的循环性** | 包含多个 PD/OQ/DE/T 循环，逐步深化 | 教学实例展示问题→实作→观察→讨论→改进的过程 |
| **STEAM 的融合度** | 五个领域都有体现，不是单领域活动 | STEAM 知识概念栏同时列出 S/T/E/A/M 的具体内容 |
| **师生对话的真实性** | 含有实际课堂对话(T/C 标注)，呈现真实教学过程 | 教学实例说明包含对话，显示幼儿思维过程 |
| **测量与记录** | 使用标准化工具（量杯、电子秤、尺）记录数据 | 教案明确列出测量工具和记录方式 |
| **连贯的脉络性** | 活动之间有逻辑递进，前一个为后一个奠基 | 例：麵粉加水实验→确定比例→做麵条→改进形状 |
| **学习指标的对应** | 选用的学习指标在教学实例中确实有体现 | 学习指标与教学实例对话直接呼应 |
| **教学反思的深度** | 包含对教学过程的反思、改进和学生成长的记录 | 教学省思栏显示教师对问题的理解和改进方向 |

⚠️ **最后那一维我们换掉了**（2026-08-20）。「教学反思的深度」要求写出「预期与实际的差异」，
而这个小程序是在活动**开始之前**用的 —— 没有「实际」可写，硬要模型写就只能编。
换成 **「目标与过程的对应」**：写出来的三条活动目标，活动过程里**真的做到了**吗？
换这一维的理由不只是「原来那维不适用」，而是它本身就是大陆教案评审最先挑的毛病 ——
目标写得漂亮，过程里没有一个环节服务它（尤其那条情感目标）。

## 三、通用教案模板结构

### 基础信息
- 教案标题（动词+对象）
- 作者及学校
- STEAM 领域标注（勾选涉及的 5 个领域）
- 适用年龄层（小班/中班/大班）

### 前置准备
- 教具照片与说明
  - 食材/材料清单
  - 工具清单（含测量工具）
  - 环境布置需求

> ⚠️ **2026-08-20：这一节以下记录的是「那本书的教案长什么样」，
> 不再是「我们输出的教案长什么样」。**
>
> 这份文档是**对原书的提炼记录**，所以保持忠实、不改写 —— 改写它等于伪造来源。
> 但我们的产出格式已经换成**中国大陆幼儿园常见的教案格式**了，因为那本书是
> **活动实录**（记录活动做完之后回头看当时怎么发生的），而这个小程序解决的是
> **活动开始之前**：老师明天要上，今天要写教案、要备材料。
>
> 换掉的只是**呈现格式**，下面第二节那 8 个质量维度、探究循环的要求、
> 5 大支柱**全部照旧生效** —— 那些是教学主张，跟用什么格式呈现无关。
>
> 两处具体的差异：
> - 环节名：书里是「引起动机 / 发展活动 / 综合活动 / 延伸活动」，
>   我们输出「导入 / 展开 / 再探索与改进 / 交流总结」（小班只有前三个里的三个）
> - 「教学省思」**我们不产出**。活动还没做，「预期与实际的差异」只能是编的。
>   8 个维度里那一维换成了「目标与过程的对应」（写出来的三条目标，过程里真做到了吗）
>
> 现在的完整结构见 `docs/design/lesson-structure-and-modes.md` 和 `api-spec.md` 第 5 节。

### 核心设计

#### 1. 教案特色说明
- 与主题的关系（是主题中的哪个阶段）
- 幼儿将获得的学习经验（3-5 条）
- 探究的核心焦点或问题

#### 2. 教学流程（4 大环节）
- **引起动机**：现象观察→产生好奇→提出问题
- **发展活动**：预测→实作→观察
- **综合活动**：分享→讨论→改进
- **延伸活动**：学习迁移/区角深化

#### 3. STEAM 知识概念表

```
S（科学）：现象观察、物质特性、科学原理
T（科技）：工具使用、技巧、步骤
E（工程）：最优比例、设计改进、问题解决
A（艺术）：美感体验、创意表现、色彩形态
M（数学）：测量、计算、数据记录
```

#### 4. 幼儿学习指标
- 选择 2-4 个对应学习指标
- 仅选择有教学实例直接体现的指标

### 实施细节

#### 5. 教学实例说明
- 师生对话（T=teacher, C=child）
- 展现问题产生过程
- 展现幼儿思维和发现
- 展现教师的引导提问
- 包含失败与改进的过程

### 反思总结

#### 6. 教学省思
- 对教学过程的回顾
- 预期与实际的差异
- 对幼儿学习的观察
- 教师专业成长的体会
- 后续改进方向

## 四、教案设计中的引导问题类型库

### 类型 1：激发预测的开放问题
```
- "你觉得会发生什么？"
- "为什么会这样？"
- "要加多少水才能变成面团？"
- "哪一种材料效果最好？"
```

### 类型 2：观察后的追问
```
- "你发现了什么？"
- "有什么不同？"
- "为什么有的...，有的...？"
- "每个小组的结果一样吗？"
```

### 类型 3：问题求解的引导
```
- "我怎么知道都一样平了呢？" → 引发使用测量工具
- "为什么切不开？" → 引发换工具思考
- "还可以做什么？" → 引发迁移和延伸
```

### 类型 4：决策与优化
```
- "哪个最适合用来做...？"
- "要怎么改进才能...？"
- "下一次应该怎么做？"
- "我们可以给他什么建议？"
```

### 类型 5：知识迁移
```
- "日常生活中，你在哪里看过这个原理？"
- "这个方法还可以用在...吗？"
- "如果要...，应该怎么做？"
```

### 类型 6：反思与总结
```
- "这个过程中，你学到了什么？"
- "为什么一开始做不好，后来能成功？"
- "用...工具和用...工具有什么不同？"
```

## 五、核心教学策略

### "放慢脚步"原则
- 不急着给答案，多提供尝试机会
- 给予充足时间让幼儿自己探索、失败、反思
- 幼儿的深刻学习来自于经历，不是被告知

### 分组探究循环
- 同一实验多组进行，变量不同（如：10cc、20cc、30cc 水量）
- 各组独立操作后展示比较
- 集体讨论找出最优方案

### 标准化工具教学
- 初期自由探索（用手、用眼睛看）
- 发现问题时引入工具（用量杯、用尺、用秤）
- 幼儿意识到工具的价值，主动采用

### 家长志工参与
- 不直接教，而是引导和观察
- 支持幼儿的实践和尝试
- 与教师建立共同的教学理念

## 六、教案设计对话树框架

```
主题问题：怎样做出好吃的__？

├─ 预测与假设阶段
│  ├─ Q: 你觉得需要什么？
│  └─ 幼儿自发提议
│
├─ 第 1 个实验循环
│  ├─ 设计：选择 1-2 个变量
│  ├─ 实施：各组独立操作
│  ├─ 观察：感官体验、记录结果
│  └─ 讨论：为什么有这样的结果？
│
├─ 问题诊断
│  ├─ Q: 遇到什么问题？
│  ├─ 幼儿陈述问题
│  └─ Q: 怎么解决？→ 引发新的实验设计
│
├─ 第 2-N 个实验循环
│  └─ [重复上述过程，逐步精细化]
│
├─ 优化与定案
│  ├─ Q: 哪个最好？为什么？
│  └─ 形成班级配方/方案
│
└─ 迁移与高峰活动
   ├─ 制作成品
   ├─ 亲子分享会
   └─ 记录学习过程
```

## 七、实际教案示例：《麵粉加水遊戲》

### 核心问题
水和麵粉多少比例才能变成好的麵团？

### 循环过程
1. 幼儿随意说数字 (5、10、60、100)
2. 自己发现需要标准化工具
3. 用量杯量 10、20、30...80cc
4. 各组实验、对比观察
5. 发现 40 克麵粉+20cc 水最适合
6. 形成食谱

### STEAM 融合
- **S**（科学）：物质特性、质地变化
- **T**（科技）：搅拌技巧、步骤
- **E**（工程）：比例优化、设计改进
- **A**（艺术）：色彩创意表现
- **M**（数学）：测量、记录数据

### 成果
班级标准食谱 + 延伸彩色麵糊画活动
