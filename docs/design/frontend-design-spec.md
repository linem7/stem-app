# 前端设计规格 · Web

2026-09-23 对照当前路由与组件整理。早期三方向设计任务书保留在 [历史快照](../handoff/2026-09-23-整理前开发约定.md)，不作为当前页面清单。

## 产品与视觉

面向幼儿园老师的手机网页，支持电脑浏览器。明亮、温馨、柔和、有条理；界面依靠暖底色、留白、字体和分隔线组织信息，不使用 emoji 作图标或装饰数字。

全简体中文，使用大陆幼教术语。推荐答案优先做成可点选卡片，自填作为补充；操作可中断，返回后可继续。

颜色及尺寸以 [设计令牌](design-tokens.md) 为准，年龄班以 [年龄班适配](age-band-adaptation.md) 为准。正文至少 14px、辅助文字至少 12px，正文对比度至少 4.5:1。产品流程详见 [PRD](../PRD-web.md)。

## 页面与信息结构

路由的事实来源是 [routes.js](../../frontend/src/router/routes.js)。

| 路径／组件 | 当前职责 |
|---|---|
| `/` | 输入一个教案想法；不堆叠历史教案和装饰模块 |
| `/redeem`、`/login` | 首次兑换激活、名单或自填身份、手机号密码登录 |
| `/c?id=会话ID` | 引导、生成、成稿、改稿共用一条对话流 |
| `/agreement` | 激活后的协议确认；`?view=1` 用于回看 |
| `s-shell` | 宽屏侧栏／窄屏抽屉承载历史和筛选 |
| `s-me` | “我的”弹窗：额度、任务、档案、记忆、反馈、字号、退出与注销 |
| `/preview` | 现存组件预览，仅开发参考，不是教师业务入口 |

不再按微信胶囊、安全区或底部 tab bar 设计页面，也不将引导、生成、成稿拆成三个独立路由。

## 关键交互

- 引导一屏 4 题，每题答案及时保存；学习模式可显示解释，不能恢复旧的一次一题流程。
- 生成异步轮询。开启内容审核时显示阶段进度，审核通过前不展示标题、正文或结构化内容；未开启审核的开发环境保留增量文本协议。
- 网络失败显示“接着等”以恢复轮询，生成失败由用户选择重试；不能因断网自动重复生成。
- 成稿修改通过“改一改”进入 AI 重写与版本流程。API 的局部编辑能力不代表教师页面已有手动编辑入口。
- 配图推荐是完整打印方案，点击填入可编辑描述；描述输入优先。记录表独占一张纸。
- Word 导出以 POST 请求获取 blob 下载，含正文与可读取的已完成配图；不含学习模式折叠解读。
- 退出位于“我的”底部，数据加载失败仍可退出；有未保存输入才提示确认。退出后清理本机状态、停止旧页面工作，并同步同浏览器其他标签页。
- 注销与退出是不同操作，保留注销确认；退出不删除业务数据或吊销其他设备凭证。
